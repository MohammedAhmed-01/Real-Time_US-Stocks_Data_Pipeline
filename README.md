## 🔍 Overview

This project implements a **real-time US stock market data pipeline** using industry-standard big data tools. A Kaggle dataset is replayed as a live stream through Kafka, processed by Spark, stored in HDFS and PostgreSQL, visualised in Power BI, enriched with an MLlib prediction model, and finally surfaced through an AI-powered RAG chat assistant — all containerised and orchestrated end-to-end.
